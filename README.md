## Версии

Релизная версия приложения задаётся полем `version` в `package.json` и показывается на экране настроек. На этапе сборки `scripts/gen-version.mjs` дополнительно создаёт уникальный идентификатор сборки, который нужен только для автообновления открытых вкладок и не заменяет релизную версию.
